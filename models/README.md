# Model Files

This directory contains model checkpoints and associated files generated during testing, development, and validation of the current implementation of HEOFS.

**Important:** The models included in this directory are not the trained models used to obtain the results reported in the associated scientific publication. They were generated using test runs and the current version of the source code and are provided for development and implementation purposes.

The original trained models used in the scientific study are held by the Institute of Atmospheric Sciences and Climate Change (ICAyCC-UNAM), as part of the project:

*“Ensemble for Early Warning of Episodes and Air Quality Forecasting. Component 3: Fuzzy Logic Model for Ozone Level Prediction.”*

This project is jointly developed by the Institute of Atmospheric Sciences and Climate Change (ICAyCC-UNAM), the Ministry of Environment and Natural Resources (SEMARNAT), the National Institute of Ecology and Climate Change (INECC), and the Environmental Commission of the Megalopolis (CAMe).

Therefore, the model files provided here should not be considered the original experimental artifacts used in the published study, nor should they be used to reproduce its reported results.
